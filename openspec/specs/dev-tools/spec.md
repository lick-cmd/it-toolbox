## Purpose

开发辅助工具集 —— JSON 压缩、JSON 美化格式化

## Requirements

### Requirement: JSON 压缩

系统 SHALL 提供 JSON 压缩能力，移除 JSON 中所有非必要空白字符，并 SHALL 保证压缩结果在语义上与原 JSON 完全等价。默认压缩路径 SHALL 保留字符串内的**原始转义字面量**，不进行规范化。

#### Scenario: 压缩格式化的 JSON

- **WHEN** 用户输入带缩进与换行的多行 JSON
- **THEN** 输出为不含换行与多余空格的单行 JSON，键值内容与顺序保持不变

#### Scenario: 语义等价

- **WHEN** 将压缩结果再次交给 JSON 美化工具处理
- **THEN** 得到的结构与压缩前的原 JSON 语义完全一致

#### Scenario: 保留字符串内空白

- **WHEN** 输入的 JSON 字符串值中本身包含空格、换行或制表符
- **THEN** 压缩结果中这些字符串内容被完整保留，不被移除

#### Scenario: 保留特殊字符转义

- **WHEN** 输入的 JSON 字符串值中包含转义字符（如 `\"`、`\n`、`\\`、Unicode 转义）
- **THEN** 压缩结果中的转义序列保持正确且可被重新解析

#### Scenario: 转义字面量不被规范化

- **WHEN** 输入的 JSON 字符串中包含可被等价改写的转义（例如 `\u0041` 可写作 `A`、`\/` 可写作 `/`）
- **THEN** 压缩结果保留其原始转义写法，不被改写为等价的其他写法

#### Scenario: 压缩与美化逐字节往返

- **WHEN** 用户将一份 JSON 先经美化（未开启键排序）再经压缩
- **THEN** 结果与对原始输入直接压缩所得结果逐字节一致

#### Scenario: 展示体积变化

- **WHEN** 压缩成功
- **THEN** 系统展示压缩前后的字节数以及节省比例

#### Scenario: 非法 JSON

- **WHEN** 用户输入不是合法 JSON
- **THEN** 系统提示解析失败并指出出错位置，不输出结果

#### Scenario: 空输入

- **WHEN** 输入区为空
- **THEN** 系统不报错、不输出内容

### Requirement: JSON 美化格式化

系统 SHALL 提供 JSON 美化能力，支持配置缩进（2 空格、4 空格、制表符），并 SHALL 支持可选的键排序、数组保持原序，以及 SHALL 展示每个值的数据类型提示。

#### Scenario: 默认缩进美化

- **WHEN** 用户输入压缩的单行 JSON 且不修改参数
- **THEN** 输出为按默认缩进（2 空格）换行展开的 JSON

#### Scenario: 缩进选项

- **WHEN** 用户选择 4 空格或制表符缩进
- **THEN** 输出按所选缩进样式格式化

#### Scenario: 键排序

- **WHEN** 用户开启「键排序」
- **THEN** 输出的每个对象内键按字典序排列，且数组元素的顺序保持不变

#### Scenario: 关闭键排序保持原序

- **WHEN** 用户关闭「键排序」
- **THEN** 输出的键顺序与输入完全一致

#### Scenario: 默认模式保留转义字面量

- **WHEN** 在未开启键排序的情况下对含转义字面量的 JSON 执行美化
- **THEN** 输出保留其原始转义写法，不被改写为等价的其他写法

#### Scenario: 键排序模式的行为提示

- **WHEN** 用户开启「键排序」
- **THEN** 界面明确提示该模式会重建键值结构，字符串中的等价转义写法可能被规范化

#### Scenario: 非法 JSON 定位

- **WHEN** 用户输入存在语法错误的 JSON
- **THEN** 系统提示解析失败，并指出出错的位置（行号与列号或字符偏移）

#### Scenario: 大体积输入

- **WHEN** 用户输入一个较大（例如超过 1MB）的 JSON
- **THEN** 系统在可接受时间内完成格式化或给出处理中的状态，界面不出现无响应

#### Scenario: 与压缩互为逆操作

- **WHEN** 用户将美化输出（**未开启键排序**）交给 JSON 压缩工具处理
- **THEN** 得到的单行 JSON 与美化前的原始输入在去除空白后完全一致

### Requirement: JSON 树形视图

系统 SHALL 在 JSON 美化工具中提供可折叠的树形视图，并与格式化输出、类型提示并列为一个可独立切换的视图。树形视图 SHALL 逐个节点展示键名、值与数据类型标签，并 SHALL 允许用户独立折叠或展开任意对象、数组节点；被折叠的节点 SHALL 以含元素个数的摘要形式呈现。树形视图中标量的文本 SHALL 与输入中的原文逐字符一致（保留转义字面量），不得显示为规范化后的等价写法；该原文保真 SHALL 只针对**值**的文本，对象成员名 SHALL 按解码后的名称展示（例如源码中的 `\u0041` 显示为 `A`）。

#### Scenario: 逐个折叠子项

- **WHEN** 用户在树形视图上折叠某一个对象或数组节点
- **THEN** 该节点的子项被收起，该行显示为含元素个数的折叠摘要（对象为 `{…} 3 键`，数组为 `[…] 3 项`），其父节点与同级节点保持原有的展开状态

#### Scenario: 折叠状态按节点独立

- **WHEN** 用户先折叠节点 A，再展开另一个节点 B
- **THEN** 节点 A 仍保持折叠，展开状态按节点独立记录，不因节点的增删而互相影响

#### Scenario: 类型标签口径一致

- **WHEN** 树形视图展示任意一个值
- **THEN** 该值旁显示其数据类型标签，且该标签与类型提示视图使用同一套口径（**无重复键**的文档中，同一份 JSON 在两个视图中的类型标签逐节点一一对应；含重复键时类型提示按对象键去重、树按源码 token 成节点，不要求一一对应）

#### Scenario: 标量保留原文转义

- **WHEN** 输入中的字符串或数字使用了可被等价改写的写法（例如 `\u0041`、`\/`、`1e2`）
- **THEN** 树形视图中该标量按原文显示，不被改写为等价的其他写法

#### Scenario: 全部展开与全部折叠

- **WHEN** 用户点击「全部折叠」，随后点击「全部展开」
- **THEN** 前者除根节点外所有节点被收起，后者恢复为全部展开

#### Scenario: 大体积输入

- **WHEN** 用户输入含大量节点的 JSON
- **THEN** 系统只渲染已展开路径上的节点，并在超出展示上限时给出明确提示，界面不出现无响应

#### Scenario: 非法输入与空输入

- **WHEN** 输入为空或不是合法 JSON
- **THEN** 树形视图显示空态或错误提示，不展示任何节点

#### Scenario: 复制与下载不受视图影响

- **WHEN** 用户在树形视图下点击复制或下载
- **THEN** 写入剪贴板或文件的内容是完整的格式化原文，不含树形视图的装饰标记

### Requirement: JSON 格式化结果的折叠

系统 SHALL 让 JSON 美化工具的**格式化结果视图**支持按容器折叠：每个跨行的对象 / 数组 SHALL 在其开括号所在行提供一个折叠开关，收起时该容器的内容行（含配对闭括号所在行）SHALL 被隐藏、该行 SHALL 显示含元素个数的摘要（对象为 `… 3 键`，数组为 `… 3 项`）。可见行的行号 SHALL 仍为原文行号，因此折叠后允许跳号。系统 SHALL 提供「全部展开」与「全部折叠」，后者 SHALL 除根以外全部收起。折叠 SHALL 只影响展示：复制与下载 SHALL 仍给出完整的格式化原文，摘要等装饰 SHALL 不进入内容列。同一行内闭合的空容器（`{}` / `[]`）与单行 JSON SHALL 不产生折叠开关；预览被截断（内容不是一份完整合法的 JSON）时系统 SHALL 不提供折叠并如实提示。

#### Scenario: 折叠某个容器

- **WHEN** 用户在格式化结果视图上折叠某个对象或数组的开括号行
- **THEN** 该容器的内容行与配对闭括号行被隐藏，该行显示含元素个数的折叠摘要，同行与同级内容保持原样，可见行的行号仍为原文行号

#### Scenario: 折叠状态按行独立

- **WHEN** 用户先折叠容器 A，再折叠容器 B，随后展开 A
- **THEN** 折叠状态按开括号行独立记录，B 仍保持折叠，A 恢复为展开

#### Scenario: 全部展开与全部折叠

- **WHEN** 用户点击「全部折叠」，随后点击「全部展开」
- **THEN** 前者除根以外所有容器被收起（各层只剩开括号行与摘要），后者恢复为全部展开

#### Scenario: 复制与下载不受折叠影响

- **WHEN** 用户在折叠状态下点击复制或下载
- **THEN** 写入剪贴板或文件的内容是完整的格式化原文，不含折叠摘要一类的装饰标记

#### Scenario: 空容器与单行 JSON

- **WHEN** 输入为单行 JSON，或美化结果里的容器写成 `{}` / `[]`（同一行内闭合）
- **THEN** 这些位置不提供折叠开关（收起与展开没有区别）；整份文本都没有跨行容器时，界面连可折叠处计数与「全部展开 / 全部折叠」入口都不出现

#### Scenario: 预览被截断时不提供折叠

- **WHEN** 格式化输出超过预览上限，预览内容因此不是一份完整合法的 JSON
- **THEN** 界面不提供折叠并如实提示 —— 折叠与语法着色同样需要完整的预览内容，而复制与下载给的是完整输出
